# Рамка crop-области в окне предпросмотра (опциональная)

## Идея

В окне `VCamPreview` опционально отображать рамку crop-области текущего
источника — чтобы видеть, какая часть исходного изображения реально
попадает в кадр виртуальной камеры.

## Мотивация

Сейчас crop настраивается в VCamSettingsUi (рамка мышью на превью), а в
VCamPreview виден только итоговый кадр. Непонятно, какую часть источника
камера «срезала», пока не открыл UI настроек. Для проверки композиции
(что попало в кадр, а что обрезано) нужна подсказка прямо в предпросмотре.

## Возможная реализация

- Настройка в `settings.json` (например, `preview.showCropFrame: bool`,
  default false) или пункт контекстного меню окна предпросмотра —
  «Показывать рамку crop» с checkmark.
- `VCamPreview` при включённой опции читает crop-секцию активного
  источника (`settings.source.type` → `static.crop*`) и рисует рамку
  поверх кадра (GDI+ Rectangle поверх уже отрисованного кадра, поверх
  letterbox-полос — рамка в координатах отображения источника).
- Отслеживание hot-reload settings.json (в предпросмотре уже есть
  reconnect/таймауты; либо перечитывать на открытии меню).
- Учитывать scaleMode (fit/cover/crop): рамка нужна только при crop;
  для fit/cover — прячем пункт/рамку.
- Отрисовка одной рамки поверх кадра ≈ не удваивает бюджет кадра
  (GDI+ HighQualityBicubic в предпросмотре уже ~11 мс/кадр — рамку
  рисовать обычным Line, не влиять на пайплайн).
