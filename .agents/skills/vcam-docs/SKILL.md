# vcam-docs — обновление документации VCam

## Шаг 1. Найти memory-файлы

```powershell
Get-ChildItem -Path "VirtualCameraMediaSource" -Filter "*.memory.md" -File
```

## Шаг 2. Прочитать каждый и решить

Для каждого файла ответить:
- Есть ли питфол, который легко повторить (COM, MF API, PowerShell, .NET, сборка)?
- Есть ли инструкция по деплою/регистрации, которой нет в AGENTS.md?

Если да → перейти к Шагу 3. Если нет → удалить файл.

## Шаг 3. Перенести питфол в AGENTS.md

1. Открыть `AGENTS.md` (корень репо).
2. Найти подходящий раздел в «Критичные питфолы» (COM, камера, запись, GPU, UI, профили, установщик, E2E, превью).
3. Добавить короткую строку: **что** → **почему** → **как избежать**.
4. Если раздел не подходит — создать новый.

## Шаг 4. Проверить AGENTS.md

1. Нет ли дублей между разделами (grep по ключевым словам).
2. Нет ли ссылок на `*.memory.md` (grep `memory`).
3. Нет ли противоречий с кодом (например, «камера 1280×720» vs нативные 1080p).
4. Нет ли устаревших версий/путов.

## Шаг 5. Удалить memory-файлы

```powershell
Get-ChildItem -Path "VirtualCameraMediaSource" -Filter "*.memory.md" -File | Remove-Item -Force
```

## Шаг 6. Проверить деградацию документов

1. Размер AGENTS.md: если > 150 строк — проверить, не появилось ли дублей или устаревших разделов.
2. Размер README.md: если > 200 строк — проверить, не описывает ли он удалённые фичи.
3. Назначение: каждый раздел должен отвечать на вопрос «зачем это?». Если нет — удалить.
4. Актуальность: ссылки на файлы/проекты должны существовать (проверить через `Test-Path` или `glob`).
5. Полнота: новые фичи должны быть описаны, старые — удалены.

## Шаг 7. Обновить README.md (если нужно)

- Состав проектов изменился → обновить таблицу.
- Новые флаги/настройки → добавить в пример settings.json.
- Удалённые фичи → убрать из описания.

## Частые ошибки

- Перенести лог задачи вместо питфола → оставить только то, что влияет на сборку/деплой/тесты.
- Создать новый раздел вместо существующего → сначала grep по AGENTS.md.
- Забыть проверить ссылки → после правки grep `memory` по AGENTS.md.
